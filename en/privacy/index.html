Privacy Policy

Updated October 4, 2026

Shatl is a free, open-source torrent client for Mac. It is developed by Igor Mamontov (Mamontov Design). This page describes what data the app and this website send over the network, where, and why. The code is open, so you can check every statement on GitHub.

In short

  • No accounts, no ads, no third-party analytics.
  • Information about your torrents and files is never sent to me or to third-party services.
  • Usage statistics are sent only with your consent.
  • I don’t sell or share data.

Usage statistics

Statistics are off by default. You can turn them on with the “Help Improve” button at first launch, or with the “Send anonymous statistics” switch in Settings, on the Data tab.

At most once a week, the app sends a report with five fields:

  • a random installation ID, created when you turn statistics on and not linked to you, your Mac, or your Apple Account;
  • the reporting week;
  • the number of launches that week;
  • the interface language;
  • the app version.

Torrents, links, file names, paths, and file contents are never part of the report. You can open a copy of the report with the “Show” button on the same tab.

Why: statistics show how many people use Shatl and help decide whether to keep supporting the app and releasing updates.

Where they are stored: reports go to a server on Cloudflare Workers, which writes them to a Cloudflare D1 database. Like any server, Cloudflare receives your IP address with the request, but the address is not written to the database.

How long: for as long as the reports are needed for Shatl statistics. If the project shuts down, the database will be deleted.

How to stop: turn off “Send anonymous statistics.” Sending stops, and the ID and any unsent report are deleted from your Mac. If you turn statistics on again, a new ID is created.

How to delete sent reports: while statistics are on, open the report with the “Show” button and send the install_id value to mamontov.design@gmail.com. I will delete all records with that ID. Once statistics are turned off, the ID is erased from your Mac, and earlier records can no longer be linked to you.

Updates

If “Check for updates automatically” is on (the default), the app downloads the list of versions from GitHub Pages once a day. To check manually, use “Check for Updates…” on the About tab.

The app downloads a new version from GitHub after you agree, or on its own if “Install updates automatically” is on. No information about your Mac is sent with the check. GitHub sees your IP address and the app name and version, as with any request to a website.

Torrent network

This is how BitTorrent works: while a torrent is downloading or seeding, its trackers and other peers can see your IP address and which torrent it is, including through DHT. Shatl does not hide your IP address.

  • In the Orbit and Nova modes, Shatl also looks for peers on your local network. Other devices on that network may see which torrents are downloading.
  • So that peers can connect to your Mac directly, Shatl asks your router to open a port (UPnP and NAT-PMP). This is on by default and can be turned off with “Open a port on the router automatically” on the Downloads tab.

Data on your Mac

The torrent list, settings, and data for resuming downloads are stored only on your Mac. Notifications are shown by macOS itself and do not pass through any server. Release builds keep no logs: the code for logging is not included in them.

Feedback

The “Write…” button on the About tab opens an email in your mail app. The email is sent only if you send it. I use your address and message only to reply.

Website

This website is hosted on GitHub Pages. GitHub may record visitors’ IP addresses in its logs. The site has no cookies and no analytics, and the font is served from the site itself. Your browser stores only the site language you chose. Links to GitHub, Telegram, Behance, and Reddit lead to third-party sites with their own rules.

Third-party services

  • GitHub: website, downloads, and updates (GitHub Privacy Statement).
  • Cloudflare: usage statistics (Cloudflare Privacy Policy).
