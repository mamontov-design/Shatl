Политика конфиденциальности

Обновлено 4 октября 2026 года

Shatl — бесплатный торрент-клиент для Mac с открытым исходным кодом. Его разрабатывает Игорь Мамонтов (Mamontov Design). Здесь описано, какие данные приложение и этот сайт передают в сеть, куда и зачем. Код открыт, поэтому каждое утверждение можно проверить на GitHub.

Коротко

  • Аккаунтов, рекламы и сторонней аналитики нет.
  • Сведения о ваших торрентах и файлах не отправляются ни мне, ни сторонним сервисам.
  • Статистика использования отправляется только с вашего согласия.
  • Я не продаю и не передаю данные.

Статистика использования

По умолчанию выключена. Включить её можно кнопкой «Помочь развитию» при первом запуске или переключателем «Отправлять анонимную статистику» в настройках, на вкладке «Данные».

Не чаще раза в неделю приложение отправляет отчёт из пяти полей:

  • случайный идентификатор установки: создаётся при включении статистики и не связан с вами, вашим Mac или Apple ID;
  • отчётная неделя;
  • число запусков за неделю;
  • язык интерфейса;
  • версия приложения.

Торренты, ссылки, имена, пути и содержимое файлов в отчёт не входят. Копию отчёта можно открыть кнопкой «Показать» на той же вкладке.

Зачем: статистика показывает, сколько людей пользуется Shatl, и помогает решать, стоит ли поддерживать приложение и выпускать обновления.

Где хранится: отчёты принимает сервер на Cloudflare Workers и записывает в базу Cloudflare D1. Вместе с запросом Cloudflare, как любой сервер, получает IP‑адрес, но в базу он не записывается.

Сколько хранится: пока отчёты нужны для статистики Shatl. Если проект закроется, база будет удалена.

Как остановить: выключите «Отправлять анонимную статистику». Отправка прекратится, а идентификатор и неотправленный отчёт удалятся с Mac. Если включить статистику снова, появится новый идентификатор.

Как удалить отправленные отчёты: пока статистика включена, откройте отчёт кнопкой «Показать» и пришлите значение install_id на mamontov.design@gmail.com. Я удалю все записи с этим идентификатором. После выключения статистики идентификатор стирается с Mac, и связать прежние записи с вами больше нельзя.

Обновления

Если включено «Проверять обновления автоматически» (так по умолчанию), раз в сутки приложение загружает список версий с GitHub Pages. Вручную проверить можно кнопкой «Проверить обновления…» на вкладке «О программе».

Новую версию приложение скачивает с GitHub после вашего согласия или само, если включено «Устанавливать обновления автоматически». Сведения о Mac при проверке не отправляются. GitHub видит IP‑адрес, название и версию приложения, как при любом обращении к сайту.

Торрент-сеть

Так устроен BitTorrent: пока торрент загружается или раздаётся, ваш IP‑адрес и то, какой это торрент, видят его трекеры и другие участники, в том числе через DHT. Shatl не скрывает IP‑адрес.

  • В режимах Orbit и Nova Shatl также ищет участников в локальной сети. Другие устройства этой сети могут увидеть, какие торренты загружаются.
  • Чтобы участники могли подключаться к вашему Mac напрямую, Shatl просит роутер открыть порт (UPnP и NAT-PMP). Это включено по умолчанию и выключается переключателем «Открывать порт на роутере автоматически» на вкладке «Загрузки».

Данные на Mac

Список торрентов, настройки и данные для продолжения загрузок хранятся только на вашем Mac. Уведомления показывает сама macOS, через серверы они не проходят. Выпускаемые версии не ведут журналов: кода для них в сборке нет.

Обратная связь

Кнопка «Написать…» на вкладке «О программе» открывает письмо в вашем почтовом приложении. Письмо уходит, только если вы его отправите. Адрес и текст я использую только для ответа.

Сайт

Сайт размещён на GitHub Pages. GitHub может записывать IP‑адреса посетителей в свои журналы. Cookie и аналитики на сайте нет, шрифт загружается с самого сайта. В браузере сохраняется только выбранный язык сайта. Ссылки на GitHub, Telegram, Behance и Reddit ведут на сторонние сайты со своими правилами.

Сторонние сервисы

  • GitHub: сайт, загрузка и обновления (политика конфиденциальности GitHub).
  • Cloudflare: статистика использования (политика конфиденциальности Cloudflare).
