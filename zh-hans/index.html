认识 Shatl。

一款基于 libtorrent、面向 Mac 的轻量级开源 BitTorrent 客户端。下载前即可选择所需文件，控制 Mac 的资源占用，并在简洁的界面中查看进度。

首次启动时需要授权。

下载 Mac 版GitHub

从容开始

下载开始前，尽在掌控。

添加 .torrent 文件或粘贴 magnet 链接。Shatl 会获取元数据，并在下载开始前显示其中的内容。

只选择你需要的内容。

选择所需文件和文件夹、保存位置，以及下载完成后是否停止做种。Shatl 会显示所选文件的大小和磁盘可用空间。

按你的方式命名下载。

不再使用技术性名称“big_buck_bunny_1080p_h264”，而是添加清晰的别名，例如“Big Buck Bunny”。Shatl 会在 Torrent 卡片中显示该名称。

按你的方式查看指标

数据——更简洁，也可以更精确。

对大多数用户而言，快速了解下载状态比逐一解读数字更重要。因此，Shatl 只显示真正有用的信息，同时也支持切换到更详细的视图。

简化版

适合大多数用户。Shatl 会对数值进行取整，只保留足以快速判断下载状态的精度。此模式为默认选项。

详情

适合希望更细致观察数据变化的用户。Shatl 会更精确地显示速度、数据量和剩余时间，同时仍会隐藏无意义或明显不可靠的数值。

系统强调色

匹配 Mac 的强调色。

Shatl 会将 macOS 中选定的强调色应用于界面元素和动画。

更多功能

每处细节，皆经深思。

从 Liquid Glass 和性能模式，到开放源代码与七种语言，Shatl 的每一处细节都让下载管理更简单、更清晰。

Liquid Glass

Shatl 采用 Apple 全新视觉语言中的原生材质与组件。

从 Tahoe 到 Golden Gate

Shatl 为 macOS 26 开发，并针对 macOS 27 的特性进一步打磨。

三种性能模式

选择 Halo、Orbit 或 Nova，无需手动调整引擎。

支持七种语言

界面支持英语、德语、西班牙语、法语、俄语、日语和简体中文。

有意义的动效

动画帮助你感知变化、平滑更新数据，并遵循系统的“减弱动态效果”设置。

基于 libtorrent

成熟可靠的引擎负责 BitTorrent，Shatl 则提供清晰易用的界面。

开放源代码

Shatl 的源代码、版本历史和更新文件均在 GitHub 上公开。

原生 Mac 体验

Shatl 的界面与核心逻辑使用 Swift 编写，专为 Apple Silicon 设计。

自适应卡片

每项下载只显示当前状态下重要的操作和指标。

不错过重要信息

下载完成或出现问题时，Shatl 会发送系统通知。应用未处于活跃状态时，Dock 图标会显示尚未查看的事件数量。

倡导合理使用

BitTorrent 是一种数据传输方式，并不意味着可以侵犯版权。Shatl 的作者反对盗版，并倡导只下载和分享合法获取的内容，尊重创作者的劳动成果。

AI 是工具，创作者是人

Shatl 在作者的主导下借助 AI 开发。AI 参与开发，但产品决策与设计始终由人负责。
